# 🛒 E-commerce Business Analysis using SQL

## 📌 Project Overview
This project focuses on analyzing real-world e-commerce data using SQL to extract meaningful business insights. It demonstrates the use of relational database concepts, joins, aggregations, and analytical queries to support data-driven decision-making.

## 🎯 Objectives
- Understand customer purchasing behavior  
- Analyze revenue generation and trends  
- Identify high-value customers  
- Discover best-selling products and categories  
- Evaluate payment performance  

## 📊 Key Insights
- Identified total revenue and business performance metrics  
- Highlighted top customers contributing to maximum revenue  
- Analyzed best-selling products based on sales volume  
- Compared category-wise revenue distribution  
- Evaluated payment status trends (successful, failed, pending)  

## 🗂️ Database Schema
The project includes structured tables:
- Customers  
- Orders  
- Order Items  
- Products  
- Payments  

## 🛠️ Tools & Technologies
- SQL (Joins, Aggregations, Group By, Subqueries)  
- Supabase (Database Management)  

## 📂 Project Files
- `ecommerce_schema.sql` – Database schema and queries  
- `project_report.pdf` – Business insights and analysis  
- `database_schema.png` – Schema visualization  

## 🚀 Business Impact
This analysis provides actionable insights that can help businesses:
- Improve customer targeting  
- Optimize inventory planning  
- Increase revenue through data-driven strategies  
- Enhance payment success rates  

## 📈 Conclusion
The project demonstrates strong SQL skills and the ability to translate raw data into meaningful business insights, making it valuable for real-world data analytics roles.
